# SARIF 2.1.0 JSONスキーマ

`sarif-schema-2.1.0.json` は SARIF 2.1.0 (errata01, OASIS Standard) の公式JSONスキーマである。

- 出典URL: https://docs.oasis-open.org/sarif/sarif/v2.1.0/errata01/os/schemas/sarif-schema-2.1.0.json
- スキーマ方言: JSON Schema draft-04
- 用途: SarifWriter の出力がスキーマ違反0件であることをテスト(SarifSchemaValidationTest)で検証する。
